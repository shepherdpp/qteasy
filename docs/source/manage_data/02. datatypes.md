## 信息 != 数据

在量化交易中，我们需要准备大量的金融数据，然而数据并不是最终目的——我们需要从数据中提取有用的**信息**，并在交易策略中用这些信息作出决策。

信息不等于数据，原因包括：

1. 某些数据本身意义不足，需要与其他数据结合才能成为可用信息；
2. 同一份数据可能包含多重信息，可以从不同角度提取；
3. 信息的定义是动态的：同样的原始列，经过不同加工可以有不同解读。

因此，把「数据表里的某一列」直接等同于「策略要用的信息」往往过于草率：数据只是信息的载体，而不是信息本身。

有些信息可以直接从数据表中读出，例如：

- 股票的开盘价、收盘价，可以直接从行情表中读取。

有些信息必须通过多表组合才能得到，例如：

- 股票的复权价格：需要价格表与复权因子表，再经计算得到。

有时同一列数据也可以读出不同信息，例如：

- 昨收与涨跌幅不同，但都可能来自同一张行情表。

例如，策略需要前复权价格时，原始数据分别在：

- `stock_daily`：股票日 K 线行情（开高低收等）；
- `stock_adj_factor`：复权因子。

表中已有「数据」，但还不是策略可直接消费的「信息」。若每次用到复权价都要手写多表对齐与换算，甚至还要把日线升成小时线，策略代码会迅速变复杂且易错——精力也会被琐碎计算占满。

为此，`qteasy` 把这类提取与换算封装为 **`DataType`**：您声明需要哪种信息，框架负责从表中取出并整理成统一形态，供策略、分析与可视化使用。

## 唯一 ID：`name` + `freq` + `asset_type`

每种内置 DataType 由下列三元组唯一确定：

| 要素 | 含义 | 常见取值 |
| --- | --- | --- |
| `name` | 类型名称（取数时最常用的 ID） | `close`、`pe`、`close\|b` |
| `freq` | 原生频率 | `d` / `w` / `m` / `q` / `1min`…；`None` 表示与频率无关 |
| `asset_type` | 资产类型 | `E` 股票、`IDX` 指数、`FD` 基金、`FT` 期货、`OPT` 期权、`None` / `Any` |

调用 `get_history_data(htype_names='close, pe')` 时，通常**只需给出 `name`**：框架会按规则在映射表中推断合适的频率与资产类型，并把结果对齐到您请求的输出频率网格上。需要精确排查或存在同名多版本时，请对照 [完整清单](../references/datatypes/index.md) 中的三元组，或用 `find_history_data` 查看匹配结果。

> **提示**：存储层的「数据表」与应用层的「DataType」不是同一概念。表结构见后续 [数据表章节](04.%20data_tables_10.md)；类型清单见 references。

## DataType 对象与三条日常路径

`DataType` 自较早版本起即作为数据管理核心对象，封装标准化的读取与换算逻辑。`qteasy` 内置一千余种预定义类型；公开的用户自定义入口若尚未稳定交付，请勿依赖尚未文档化的私有注册接口（见下文「自定义」）。

日常有三条路径，按场景选用：

### 路径 A：`get_kline`（OHLCV 语法糖）

标准开高低收与成交量，推荐用 `qt.get_kline(..., as_panel=True)` 快速得到 `HistoryPanel`。它是面向 K 线的便捷封装；底层仍走同一套 DataType / 取数管线。

```python
import qteasy as qt

hp = qt.get_kline(
    shares='000300.SH, 000001.SZ',
    start='20230101',
    end='20230131',
    freq='D',
    as_panel=True,
)
print(hp.htypes)
```

### 路径 B：`get_history_data`（任意内置 ID）

需要估值、财务、复权价等任意内置类型时，用 `htype_names` 写出类型名称：

```python
import qteasy as qt

# as_data_frame=False → HistoryPanel；True（默认）→ dict[str, DataFrame]
data = qt.get_history_data(
    htype_names='close, pe, pb',
    shares='000001.SZ',
    start='20230101',
    end='20230131',
    as_data_frame=True,
)
print(list(data.keys()))
```

### 路径 C：直接构造 `DataType`（底层 / 演示）

需要显式指定三元组、或演示单类型拉取时，可构造 `DataType` 并调用 `get_data_from_source`：

```python
import qteasy
from qteasy.datatypes import DataType

# 格力电器后复权收盘价（需本地已有相应表数据）
close_b = DataType(name='close|b', asset_type='E', freq='d')
close_b.get_data_from_source(
    datasource=qteasy.QT_DATA_SOURCE,
    symbols='000651.SZ',
    starts='2025-02-01',
    ends='2025-02-27',
)
```

多数研究与回测准备场景，路径 A / B 即可；路径 C 适合排查单一类型或编写更底层的脚本。

## 获取方式（`acquisition_type`）导览

内置类型在映射表中带有 **获取方式** 字段，决定框架如何从表中取出信息。您不必在业务代码里填写该字段，但理解它有助于选对类型、并在清单分册中快速定位。

下列说明与当前代码中的取值对齐（完整分册见 [catalog_index](../references/datatypes/_generated/catalog_index.md)）：

| 获取方式 | 含义（用户向） | 典型例子 |
| --- | --- | --- |
| `direct` | 按区间从单表单列直读 | `close`、`vol`、多数财务字段 |
| `basics` | 与时间无关的基本信息 | `stock_name`、`industry` |
| `adjustment` | 用另一表（如复权因子）修正后输出 | `close\|b`、`close\|f` |
| `reference` | 引用/关联型读取 | 清单中 `reference` 分册 |
| `selection` | 先按键筛选再取值 | 按交易所筛选的交易日历类字段 |
| `composition` | 成份表筛选并行列变换 | 指数成份相关 |
| `event_signal` | 事件发生时产生信号 | 涨跌停、分红配股等信号类 |
| `event_status` / `event_multi_stat` / `selected_events` | 事件状态或时段填充 | 停牌、管理层等 |

> **提示**：清单每一行的 `table_name` 列帮助您对照「该信息来自哪张本地表」——下载与表结构仍见 DataSource / 数据表章节；此处只关心「提取出的信息叫什么」。

## 如何发现全部内置类型

### 1. `find_history_data`（推荐）

支持精确名称、模糊匹配、中文描述与通配符：

```python
import qteasy as qt

qt.find_history_data('pe')
qt.find_history_data('每股收益')
qt.find_history_data('ep*', fuzzy=True)

df = qt.find_history_data('close', as_data_frame=True)
print(df.columns.tolist())
print(df.head())
```

### 2. `get_dtype_map()`

在交互环境中获取完整映射表（DataFrame，索引为 `(dtype, freq, asset_type)`）：

```python
from qteasy import datatypes

dtype_map = datatypes.get_dtype_map()
print(len(dtype_map))
print(dtype_map.head(20))

# 若将来存在用户扩展映射，可一并查看
dtype_map_all = datatypes.get_dtype_map(include_user_defined=True)
```

### 3. 文档中的完整清单

按 `acquisition_type` 分册浏览：[内置 DataType 完整清单](../references/datatypes/index.md)。清单由 `docs/scripts/generate_datatype_catalog.py` 生成并入库；发版或变更内置映射后需重跑脚本。

## 自定义 DataType

内置类型已覆盖绝大多数表字段与常用复权/事件信息。面向用户的稳定「一键注册自定义 DataType」若尚未作为公开 API 交付，请勿依赖实验性或未文档化的入口。需要尚未内置的复合指标时，可先用 `get_history_data` 取出原子字段，再在 `HistoryPanel.assign` / 策略 `realize()` 中计算（教程见 [玩数据与因子分析](../tutorials/2.5-historypanel-data-analysis.md)）。

## 小结与下一步

- DataType 描述的是**信息**，不是裸表列；唯一 ID 为 `name` + `freq` + `asset_type`。
- 日常优先 `get_kline` / `get_history_data`；用 `find_history_data` 或 [完整清单](../references/datatypes/index.md) 发现类型。
- 数据表章节回答「本地存了什么」；本章与清单回答「能提取什么信息」。

当需要在同一时间轴上同时携带多只标的、多种数据类型（例如 OHLC 与成交量一并参与计算或出图）时，下一章 [HistoryPanel（历史数据面板）](02.5.%20historypanel.md) 介绍如何把结果收拢为三维面板；制图见 [HistoryPanel 可视化](02.6.%20historypanel_visual.md)。
