# HistoryPanel 数据面板基础操作

在完成前两章「入门」和「获取并管理金融数据」之后，我们已经可以：

- 在本地配置好数据源并下载所需的历史数据；
- 使用 `get_history_data()` 或 `get_kline()` 获取价格、成交量等基础行情。

接下来，我们将通过本篇及后续章节，重点介绍 `HistoryPanel` 对象：先掌握**容器本身**的性质与基本操作，再进入因子分析与可视化工作流。

> **关于 `HistoryPanel`**：`HistoryPanel` 是 `qteasy` 提供的**三维历史数据容器**（标的 × 时间 × 指标），用于在取数之后统一管理、切片、扩列与对齐；本篇只讲**对象性质与基本操作**。
>
> **本篇覆盖**：
> - 创建面板并查看结构（`shape` / `shares` / `hdates` / `htypes`）；
> - 切片与筛选（`slice` / `segment` / `loc` / 列访问）；
> - 列读写与 `assign` 扩列；
> - `align_to` 对齐两块面板；
> - 与 `DataFrame` 互转。
>
> **注**：收益率、K 线指标、`where` 掩码、组合粗验、完整回测等见 [使用 HistoryPanel 操作和分析历史数据](2.5-historypanel-data-analysis.md)；完整回测交给 `Operator` / `Backtester`，迁移路径见 [从 HistoryPanel 研究到 Strategy / Operator](2.5-historypanel-data-analysis.md#从-historypanel-研究到-strategy--operator迁移路径)。

> 更完整的 API 说明可参考 [HistoryPanel API 参考](../api/HistoryPanel.rst)（含「列属性访问、比较与 ``loc``」与 ``where`` 专节）。

## 0. 数据检查——创建您的第一块 HistoryPanel

若您已经完成了 [获取并管理金融数据](2.0-get-data.md) 的学习，并下载了**最小数据集**，可按本节 checklist 确认：本地数据已就绪，且您能创建并「看见」一块 `HistoryPanel`。

**前置条件**：已配置好 `tushare_token`，且已下载 [最小数据集清单](2.0-get-data.md#最小数据集清单供-25-使用) 中的表（至少含 `index_daily` 或 `stock_daily`）。

**本节目标**：

- [ ] 用 `get_kline(..., as_panel=True)` 得到 `HistoryPanel`
- [ ] 打印 `shape` / `shares` / `htypes` 并理解三维含义
- [ ] 用 `print(hp)` 看见「多 DataFrame 堆叠」的直观输出

```python
import qteasy as qt

# 获取沪深 300 + 平安银行在 2023 年 1 月的日线 OHLCV，直接返回 HistoryPanel
hp = qt.get_kline(
    shares='000300.SH, 000001.SZ',
    start='20230101',
    end='20230131',
    freq='D',
    as_panel=True,              # True：返回 HistoryPanel；False：返回 dict[str, DataFrame]
)
print('shape:', hp.shape)
print('shares:', hp.shares)
print('htypes:', hp.htypes)
print(hp)
```

> 当上面的代码能正常打印 `shape` 与面板内容时，说明您下载的数据已经可以完成本篇后续操作。下文各节默认沿用同一块 `hp`（双标的、2023 年 1 月），以减少重复取数。
>
> **注**：若 `get_kline` 返回时间长度很短或报错，请先回到 [获取并管理金融数据](2.0-get-data.md) 补齐数据。因子计算、组合粗对比等请进入 [玩数据与因子分析](2.5-historypanel-data-analysis.md)。

可运行出图预览见仓库根目录 `examples/historypanel_basic_plot.py`（单标的全年示例，参数可按本节改写）。

## 1. 三维结构：HistoryPanel 是什么

了解如何创建面板之后，接下来需要建立对数据结构的心智模型。

`HistoryPanel` 在内存中对应一个三维 `numpy.ndarray`，三条轴依次为：

| 轴 | 含义 | 常用属性 |
| --- | --- | --- |
| 第 0 维 | 标的（证券代码等） | `shares` |
| 第 1 维 | 时间（历史日期或时刻） | `hdates` |
| 第 2 维 | 数据类型（如 `open`、`close`、`vol`） | `htypes` |

`hp.shape` 返回 **`(M, L, N)`**，分别对应 **股票数 × 时间长度 × 数据类型数**，与上表顺序一致。可以把它理解为：许多张「时间 × 指标」的二维表，在**标的**方向上再叠一层；同一面板内，各标的、各指标在时间上是对齐的。

打印 `hp` 可以直观地看到它的数据结构——每只股票一张小表，整块面板再把这些表堆叠起来：

```python
>>> print(hp)

2023-01-05  3913.49  3974.88  3912.26  3968.58  116502395.0

...

```

```python
>>> print('HistoryPanel shape:', hp.shape)
>>> print('shares:', hp.shares)
>>> print('htypes:', hp.htypes)
>>> print('hdates (head):', hp.hdates[:3])

```

与 [获取并管理金融数据](2.0-get-data.md) 中默认的 **`dict[str, DataFrame]`** 相比：

- 需要**快速查看单标的**时，用 `get_history_data` 默认返回的 dict 很方便；
- 需要**多标的、多指标统一切片与运算**时，用 `HistoryPanel`（`as_panel=True` / `as_data_frame=False`）更合适。

> **提示**：空面板、单标的、单列指标都是合法边界；`hp.values` 才是底层 `(M, L, N)` 数组，切片操作通常返回新的 `HistoryPanel`，而不是裸 `ndarray`。

## 2. 获得 HistoryPanel 的三种方式

创建入口建议在本节省一次理清，后文不再重复。

| 方式 | API | 适用场景 |
| --- | --- | --- |
| A（推荐） | `qt.get_kline(..., as_panel=True)` | 标准 OHLCV，教程主线 |
| B | `qt.get_history_data(..., as_data_frame=False)` | 自定义 `htype_names` |
| C（理解用） | `HistoryPanel(values, levels, rows, columns)` | 合成小面板、教学演示 |

**方式 A**（与 §0 相同）：

```python
hp = qt.get_kline(
    shares='000300.SH, 000001.SZ',
    start='20230101',
    end='20230131',
    freq='D',
    as_panel=True,
)
```

**方式 B**：需要指定更细的字段名时：

```python
hp_b = qt.get_history_data(
    htype_names='open, high, low, close, vol',
    shares='000300.SH, 000001.SZ',
    start='20230101',
    end='20230131',
    as_data_frame=False,        # False：返回 HistoryPanel
)
```

**方式 C**：不依赖本地数据源，用小型数组构造面板（便于理解标签与 `shape`）：

```python
import numpy as np
import pandas as pd
from qteasy import HistoryPanel

# 2 只标的、4 个交易日、3 种数据类型 → shape (2, 4, 3)
values = np.array(
    [
        [[1.0, 1.1, 100], [1.2, 1.3, 110], [1.15, 1.2, 105], [1.25, 1.28, 120]],
        [[10.0, 10.5, 200], [10.2, 10.8, 210], [10.1, 10.4, 205], [10.3, 10.9, 215]],
    ],
    dtype=float,
)
hp_demo = HistoryPanel(
    values=values,
    levels=['000001.SZ', '000002.SZ'],
    rows=pd.date_range('2025-01-02', periods=4, freq='B'),
    columns=['open', 'high', 'vol'],
)
print(hp_demo.shape, hp_demo.shares, hp_demo.htypes)
```

> **提示**：日常研究优先方式 A / B；方式 C 的更多说明见参考文档 [HistoryPanel（历史数据面板）](../manage_data/02.5.%20historypanel.md)。

## 4. 切片与筛选：缩小标的、时间与指标范围

多标的研究中，您经常需要「只看某几只股票」「只看某段日期」「只看 close 列」。`HistoryPanel` 提供了一组专用方法。

> **注意**：下列方法默认返回**新的** `HistoryPanel`，不会修改原对象。

| 操作 | API | 作用轴 |
| --- | --- | --- |
| 按名筛选 | `hp.slice(shares=..., htypes=...)` | 标的 / 指标 |
| 按日期 | `hp.segment(start, end)` | 时间（闭区间） |
| 按行号 | `hp.isegment(i, j)` / `hp.loc[-10:]` | 时间 |
| 取列 / 子面板 | `hp['close']`、`hp.close` | 指标 → 子面板 |
| 通用索引 | `hp[i, j, k]` / `subpanel` | 三维（简要） |

下面从 §0 的 `hp` 切出「仅 close + 仅平安银行 + 最近 10 个交易日」：

```python
# 4.1 按标的与指标名筛选
hp_close = hp.slice(shares='000001.SZ', htypes='close')
print('slice shape:', hp_close.shape, 'htypes:', hp_close.htypes)

# 4.2 按日期区间（闭区间）
hp_seg = hp.segment('20230110', '20230120')
print('segment hdates:', hp_seg.hdates[0], '→', hp_seg.hdates[-1])

# 4.3 按行号 / loc（仅沿时间轴）
hp_last10 = hp.loc[-10:]        # 等价于沿 hdates 取最后 10 行
print('loc[-10:] length:', hp_last10.shape[1])

# 4.4 取列：合法标识符可用属性，含 | 的复权列名须用方括号
hp_c = hp.close                 # 等价 hp['close']，返回单列子面板
print('close-only htypes:', hp_c.htypes)
```

关于 `hp.loc`：它**只沿时间（hdates）轴**筛选，等价 `hp[:, :, key]`。格点条件（例如「收盘价 > 某阈值」）请用 `where` 生成 bool 掩码，再交给带 `mask=` 的研究接口——详见 [生成研究用 bool 掩码](2.5-historypanel-data-analysis.md#生成研究用-bool-掩码where)。

> **提示**：`hp[i, j, k]` / `subpanel(...)` 可做更细的三维索引；日常切片优先用上表中的具名方法，可读性更好。

## 5. 列访问、写入与 `assign` 扩列

除了读取已有列，研究中经常需要**写入**或**派生**新列（价差、比值等）。

**只读访问**：

- 列名为合法 Python 标识符时：`hp.close` 等价于 `hp['close']`；
- 复权列名含 `|`（如 `close|b`）时，须用方括号：`hp['close|b']`。

**写入 / 覆盖**（原地修改当前面板）：

```python
import numpy as np

# 写入一列：可广播到 (M, L) 的数组或标量；同名列会被覆盖
hp['mid'] = (hp['high'].values[:, :, 0] + hp['low'].values[:, :, 0]) / 2.0
print('after setitem htypes:', hp.htypes)
```

**`assign`：一次派生多列**（默认返回新面板）：

```python
# inplace=False（默认）：返回新 HistoryPanel，不修改原对象
hp2 = hp.assign(
    spread=lambda p: p['close'].values[:, :, 0] - p['open'].values[:, :, 0],
    up_ratio=lambda p: p['close'].values[:, :, 0] / np.maximum(p['open'].values[:, :, 0], 1e-6),
)
print('new columns:', hp2.htypes[-2:])

# 同一次调用内，后面的列可以引用前面刚新增的列
hp3 = hp.assign(
    a=lambda p: p['close'].values[:, :, 0] + 1.0,
    b=lambda p: p['a'].values[:, :, 0] * 2.0,
)
```

> **注意**：`assign` 对已有列名采用「覆盖」语义。技术指标（均线、MACD 等）的扩列请使用 `hp.kline.*`，见 [叠加 K 线技术指标](2.5-historypanel-data-analysis.md#叠加-k-线技术指标)；更完整的 `assign` 示例亦见该篇「在 HistoryPanel 中派生新列」一节。

## 6. 两块面板对齐：`align_to` 与合并前纪律

当您手里有两块 `HistoryPanel`（例如不同时间拉取、或不同股票池），想做逐元素运算时，需要特别注意：直接对 `.values` 做 NumPy 运算**不会**自动对齐 `shares` 与 `hdates`，可能出现「看起来能算、其实错行」的 silent bug。

因此建议固定流程：**先对齐，再计算**。

```python
# 构造两块 htypes 同构、但 shares / hdates 可能不完全一致的面板
hp_a = qt.get_kline(
    shares='000300.SH, 000001.SZ',
    start='20230101',
    end='20230120',
    freq='D',
    as_panel=True,
).slice(htypes='close')

hp_b = qt.get_kline(
    shares='000001.SZ, 600519.SH',
    start='20230110',
    end='20230131',
    freq='D',
    as_panel=True,
).slice(htypes='close')

# align_to 要求两侧 htypes 名称与顺序完全一致；返回对齐后的 (a, b)
a1, b1 = hp_a.align_to(hp_b, join='inner')   # 交集对齐
print('aligned shares:', a1.shares)
print('aligned shape:', a1.shape, b1.shape)
ratio = a1.values / b1.values                # 此时逐元素运算不会错行
```

> **提示**：多表拼 `close` + `pb`、手工同构列名等见 [多源数据拼成 HistoryPanel](2.5-historypanel-data-analysis.md#多源数据拼成-historypanel价格--基本面示例)；日线升周线等频率转换见该篇「对齐与重采样」相关小节。

## 7. 与 pandas 互转

`HistoryPanel` 与 pandas 生态衔接的两条常用路径：

```python
# 单标的 → DataFrame（宽表）
df_one = hp.to_share_frame('000300.SH')
print(df_one.columns.tolist())

# 多标的 → dict[str, DataFrame]
by_share = hp.to_df_dict(by='share')
print('keys:', list(by_share.keys()))
df_000001 = by_share['000001.SZ']
```

在 `DataFrame` 上完成分析后，若要把结果写回面板：可用 `assign` / `__setitem__` 把 `(M, L)` 数组写回，或重新 `get_kline` / `get_history_data` 取数后再派生。

> **提示**：发表级截面回归、长表导出等见 [导出到 pandas / statsmodels](2.5-historypanel-data-analysis.md#导出到-pandas--statsmodels宽表长表与截面回归)。

## 8. 副本语义与 `inplace`

初学时容易混淆：「调用了方法，原面板到底改没改？」下面这张表帮助您建立默认预期：

| 操作 | 默认行为 | 说明 |
| --- | --- | --- |
| `slice` / `segment` / `head` / `tail` / `loc` | 返回**新**面板 | 不修改原对象 |
| `assign(..., inplace=False)` | 返回**新**面板 | 推荐分析链用法 |
| `assign(..., inplace=True)` / `hp['col'] = ...` | **原地**修改 | 覆盖同名列 |
| `kline.*(inplace=True)` | **原地**扩列 | 详见后续玩数据教程 |

```python
hp_orig_htypes = list(hp.htypes)
hp_new = hp.assign(factor=lambda p: p['close'].values[:, :, 0] / 100.0, inplace=False)
print('original unchanged:', hp.htypes == hp_orig_htypes)
print('new panel has factor:', 'factor' in hp_new.htypes)
```

> **提示**：做因子分析时，建议默认 `inplace=False`，保留原始 OHLCV 面板，便于对比与回退。
