# HistoryPanel 操作和分析历史数据

在完成「入门」「获取并管理金融数据」，以及（建议阅读）[HistoryPanel 数据面板基础操作](2.4-historypanel-basics.md) 之后，我们已经可以：

- 在本地配置好数据源并下载所需的历史数据；
- 创建 `HistoryPanel`，并完成切片、扩列、对齐与 `DataFrame` 互转等容器级操作。

本章将在此基础上，通过完整小例子演示如何用 `HistoryPanel` **玩数据**（因子、出图、组合粗验）：

> **关于`HistoryPanel`**: `HistoryPanel`类是`qteasy`提供的**因子研究与粗验**容器对象，它提供了一系列量化金融分析常用的数据分析工具，便于用户「玩数据」（进行数据分析、解析以及数据背后的关联挖掘），以及可视化图表，便于用户“目视筛因子”；
> 
> `HistoryPanel`的功能包括：
>- 统一管理多标的、多指标的历史数据；
>- 计算收益率、波动率等简单因子；
>- 叠加 K 线技术指标；
>- 识别部分蜡烛形态；
>- 使用 ``where`` 生成与数据同形的 **bool 掩码**，为后续带 ``mask=`` 的研究接口做准备；
>- 使用 **列属性**（如 ``hp.close``）、**比较运算**（返回 ``numpy`` 布尔数组，可与 ``where`` 衔接）以及 **``hp.loc``**（仅沿时间轴筛选，等价 ``hp[:, :, key]``）。
>- 通过对数据的筛选实现简单的“回测”分析；
>
> **注**：`HistoryPanel`并不支持**完整回测**功能（包含费用计算、交割、MOQ、信号类型控制以及详细交易报告等元素），完整的回测仍须交给 `qteasy` 提供的 `Operator` 对象和 `Backtester` 来实现，详见 [从 HistoryPanel 研究到 Strategy / Operator](#从-historypanel-研究到-strategy--operator迁移路径)。容器结构与基本切片若尚不熟悉，请先阅读 [HistoryPanel 数据面板基础操作](2.4-historypanel-basics.md)。

> 更完整的 API 说明可参考 [HistoryPanel API 参考](../api/HistoryPanel.rst)（含「列属性访问、比较与 ``loc``」与 ``where`` 专节）。

## 准备数据：获取一个 HistoryPanel

> 若您已读完 [HistoryPanel 数据面板基础操作](2.4-historypanel-basics.md)，对本节三维结构与 `get_kline` 创建方式已熟悉，可直接跳到下一节「计算收益率与波动率因子」。

当我们已经在数据源中下载了股票的价格数据以后，就可以通过 `qt.get_kline()` 或 `qt.get_history_data()` 获取 `HistoryPanel`了。

例如，下面的代码可以获取沪深300指数（`000300.SH`）和平安银行 (`000001.SZ`) 在2023年1月的全部日K线数据：

```python
import qteasy as qt

# 获取近一年日线 OHLCV，并直接返回 HistoryPanel
hp = qt.get_kline(
    shares='000300.SH, 000001.SZ',
    start='20230101',
    end='20230131',
    freq='D',
    as_panel=True,              # True：返回 HistoryPanel， False: 返回一个字典，包含多个DataFrame对象
)
```
`HistoryPanel` 的数据结构是一个三维的ndarray，它相当于多个结构相同的 `DataFrame` 堆叠起来，其中每一个 `DataFrame` 包含一只股票/指数/基金的各种历史数据，而整个 `HistoryPanel` 则包含了所有股票/指数/基金的数据。

## 计算收益率与波动率因子

了解 `HistoryPanel` 的基本操作以后，接下来我们可以进一步了解如何进行基础的金融数据分析计算。

`HistoryPanel` 内置了针对价格序列的收益 `returns` 与波动率 `volatility` 计算接口：

> **注意**：`returns` `volatility` 这两个方法不会修改原来的 `HistoryPanel`，只会返回一个新的 `DataFrame` 对象或者 `HistoryPanel`

```python
# 2.0 准备股票和指数在2023年全年的数据
hp = qt.get_kline(
    shares='000300.SH, 000001.SZ',
    start='20230101',
    end='20231231',
    freq='D',
    as_panel=True,
)
# 2.1 计算简单收益率（simple return）
ret = hp.returns(
    price_htype='close',
    method='simple',    # 或 'log'
    periods=1,
    as_panel=False,     # 返回一个新的 DataFrame: index=时间, columns=shares
)
print('日收益率:\n', ret.tail())

# 2.2 在收益率基础上计算 20 日滚动波动率
vol = hp.volatility(
    window=20,
    price_htype='close',
    method='simple',     # simple: 简单波动率，log: 指数波动率
    annualize=True,     # 年化波动率
    as_panel=True,     # 返回 HistoryPanel, 新的hp包含的股票数量与原hp相同，但数据类型只有volatility一个
)
print('20 日年化波动率:\n', vol.tail())
```

典型用法是：

- 将 `ret` 或 `vol` 当作**因子值矩阵**（时间 × 股票），用于目视筛选、截面打分或与 §5 的 `rank`/`zscore` 联用；
- 若结论需要严肃评价，请把同一经济含义写进 `Strategy.realize()`，交给 `Operator` 回测（见 **§9**）。

## 叠加 K 线技术指标

当 `HistoryPanel` 中包含 OHLC 数据时，可以通过 `hp.kline` 访问一批常用技术指标：

> `HistoryPanel.kline` 是一个K线技术指标访问器，它打包了一系列K线技术指标计算方法，用于快速计算 `hp` 中所有股票的K线技术指标并将计算结果添加到返回的`hp`中:
> - `hp.kline.sma(...)` 简单移动均线：会在 `htypes` 中追加一列，例如 `sma_20`；
> - `hp.kline.macd(...)` MACD指标：会追加 `macd_xxx`、`macd_signal_xxx`、`macd_hist_xxx` 三列；
> - `hp.kline.ema(...)` 指数移动均线指标，会在原 hp 中追加 `ema_xxx` 列
> - `hp.kline.bbands(...)` 布林带线指标
> - `hp.kline.kdj(...)` KDJ指标

例如：

```python
# 基于 close 价格生成 20 日简单移动平均线
hp_ma = hp.kline.sma(window=20, price_htype='close')
print('新增 htypes:', hp_ma.htypes)

# 再叠加 MACD 指标
hp_ma_macd = hp_ma.kline.macd(price_htype='close')
print('叠加 MACD 后的 htypes:', hp_ma_macd.htypes)

# 将单只股票切成 DataFrame，方便在 pandas / sklearn 中继续处理
df_300 = hp_ma_macd.to_share_frame('000300.SH')
print(df_300.tail())
```
这里：

- 最终通过 `to_share_frame(share)` 得到标准的二维 `DataFrame`，可直接与其他数据源联立分析。

### inplace：原地扩列（减少拷贝）

默认情况下，`kline.*` 返回 **新** `HistoryPanel`（不污染原对象）。当您希望在同一个面板上连续追加多列、并减少中间对象时，可以使用 `inplace=True`：

```python
# 在原面板上原地追加两列，并返回原面板（支持链式）
hp2 = hp.kline.sma(window=20, inplace=True).kline.macd(inplace=True)
assert hp2 is hp
print('原地扩列后的 htypes:', hp.htypes)
```

> 提示：当新列名与已有列名冲突时，`kline.*` 会抛出 `ValueError`，避免静默覆盖。

### 第一入口：research_preset（一行拼列 + 直接出图）

在 §0 的最小闭环中，我们已经用过 `research_preset`：它的作用是把 OHLCV、MACD、均线等常用列**一次性**追加到 `HistoryPanel` 上，再交给 `plot()` 出图。相比手动链式调用 `kline.sma()`、`kline.macd()`，预设更适合「数据刚下载完、想立刻看到一张完整技术图」的场景。

> **注意**：预设只在您**显式调用** `research_preset` 时计算新列；`plot()` 本身不会偷偷追加未声明的指标列。

下面的代码与 §0 中的用法相同，这里单独列出以便查阅参数含义：

```python
# 生成 OHLCV + MACD + SMA20（预设名以 API 文档为准）
hp_preset = hp.research_preset('ohlcv_macd_ma', inplace=False)  # 返回新面板，不修改原 hp
print('preset htypes tail:', hp_preset.htypes[-8:])

# 多标的时可分页展示（不再静默只画前 5 只）
fig = hp_preset.plot(
    shares=hp_preset.shares,
    max_shares_per_figure=3,  # 每张图最多 3 只，避免过密
    page=1,                   # 第一页
)
```

当输入面板缺少预设所需的输入列（例如没有完整的 OHLC）时，会抛出 `ValueError`，信息中包含缺失列列表与补齐建议；请回到 [2.0](2.0-get-data.md) 确认 K 线数据已下载完整。

## 在 `HistoryPanel` 中派生新列

除了 K 线访问器 `kline` 提供的标准技术指标外，研究中经常需要根据已有列**自定义**新因子，例如价差、涨跌幅比例、归一化后的指标等。`HistoryPanel` 支持自定义派生新的列，例如:

```python
import numpy as np

# 派生价差列：价差、收盘/开盘比例
hp['spread'] = hp.close.values - hp.open.values
hp['up_ratio'] = hp['close'].values / np.maximum(hp['open'].values, 1e-6)

print('新列:', hp.htypes[-2:])
```

除了上面的用法，`HistoryPanel` 还提供了 `assign` 方法：
``HistoryPanel.assign()`` 允许您在**一次调用**里派生多列，关键字参数名即新列名（htype），非常适合把「中间计算步骤」收拢成可读的配置式写法。

> **注意**：默认 `inplace=False`，`assign` 返回**新的** `HistoryPanel`，不会修改原对象；与 §3.1 的 `kline(inplace=True)` 语义不同，使用时请留意。

下面的例子假设 `hp` 已包含 `close` 与 `open` 列（可沿用 §2 中准备的 2023 年数据）：

```python
import numpy as np

# 一次派生两列：价差、收盘/开盘比例
hp2 = hp.assign(
    spread=lambda p: p['close'].values[:, :, 0] - p['open'].values[:, :, 0],
    up_ratio=lambda p: p['close'].values[:, :, 0] / np.maximum(p['open'].values[:, :, 0], 1e-6),
)
print('新列:', hp2.htypes[-2:])
```

说明：

- 关键字参数名称即新列名；值可以是接收当前 `HistoryPanel` 的函数（参数 `p`），也可以是可广播到 `(M, L)` 的数组或标量；
- **同一次调用内**，后面的列可以引用前面刚新增的列，例如：

```python
hp3 = hp.assign(
    a=lambda p: p['close'].values[:, :, 0] + 1.0,
    b=lambda p: p['a'].values[:, :, 0] * 2.0,   # 依赖上一行刚生成的列 a
)
```

若希望在**原面板**上原地扩列（减少中间对象），可以写：

```python
hp.assign(inplace=True, factor=lambda p: p['close'].values[:, :, 0] / 100.0)
```

> **提示**：与 `hp['col'] = ...` 一样，`assign` 对已有列名采用「覆盖」语义；在空面板上调用 `assign` 会抛出 `ValueError`。

## 横截面 rank 与 zscore（cs/ts）

多标的研究中常见的两类标准化需求是：

- **截面（cross-sectional）**：固定某个交易日，对所有股票的因子值做标准化或排名；
- **时序（time-series rolling）**：固定某只股票，对它自己的历史序列用滚动窗口做标准化。

`HistoryPanel.rank()` 与 `HistoryPanel.zscore()` 提供了这两类最基础变换（仅做数值变换，**不做**回归推断或显著性检验）。下面的代码仍基于 §2 中的 `hp`（2023 年沪深 300 + 平安银行）：

```python
# 5.1 截面排名：逐日对 share 维做排名，结果追加列 rank_close
hp_rank = hp.rank(by='close')

# 5.2 截面 zscore：逐日横截面标准化
hp_cs = hp.zscore(by='close', method='cs')     # 追加列 cs_z_close

# 5.3 时序 zscore：逐股滚动标准化（须指定 window）
hp_ts = hp.zscore(by='close', method='ts', window=20)   # 追加列 ts_z_close_20
```

> **提示**：`zscore(method='cs')` 与 `zscore(method='ts')` 含义完全不同；使用时务必显式传入 `method`，并在 `ts` 场景提供 `window`，避免把「截面标准化」误当成「时序标准化」。

### 对齐与重采样（align_to / resample）：避免 silent 错行

当您手里有两块 `HistoryPanel`（例如价格面板与基本面面板），想做逐元素运算（相除、相减）时，需要特别注意：`HistoryPanel` **不会**在运算符里自动对齐两块面板的 `shares` 与 `hdates`。若直接对 `.values` 做 NumPy 运算，可能出现「看起来能算、但其实错行」的 silent bug。

因此建议固定流程：**先对齐，再计算**。

```python
# hp_a 与 hp_b 的 shares/hdates 不一定一致
a1, b1 = hp_a.align_to(hp_b, join='inner')   # 交集对齐：只保留共同 shares 与共同日期
ratio = a1.values / b1.values                # 此时逐元素运算不会错行
print('aligned shape:', a1.shape, b1.shape)
```

当您需要把日线变成周线/月线等更低频数据时，可使用 `resample()`，并**显式**指定每一列的聚合规则（避免语义不明）：

```python
# 典型 OHLCV 周线：open=first, high=max, low=min, close=last, vol=sum
hp_w = hp.resample('W', agg={
    'open': 'first',
    'high': 'max',
    'low': 'min',
    'close': 'last',
    'vol': 'sum',
})
print('weekly dates:', hp_w.hdates[:3], '...')
```

> **提示**：`resample()` 要求 `agg` 覆盖全部 `htypes`。对于非 OHLCV 的自定义因子列，您需要自行决定 `'last'` / `'mean'` 等聚合方式并写进 `agg`。

### 用 (M,L) mask 做 plot 高亮（事件日/信号日）

在因子研究中，您经常会得到一个二维布尔矩阵，表示「每只股票在哪些日期满足条件」（例如事件日、信号日、可交易池）。`HistoryPanel.plot()` 的 `highlight={'condition': mask_ml}` 支持把它映射到图形中的高亮点：

- 若 `mask_ml.shape == (M_plot, L)`，其中 `M_plot` 为当前 `plot(shares=...)` 选中的股票数，则按绘图 share 顺序对应；
- 若 `mask_ml.shape == (M_all, L)`，其中 `M_all == len(hp.shares)`，则按 **share 名**抽取当前绘图子集（避免 silent 错行）；
- 当 `layout='overlay'` 时默认 **primary-only** 显示高亮。

```python
import numpy as np

M, L, _ = hp.shape
mask_ml = np.zeros((M, L), dtype=bool)
mask_ml[:, -1] = True                      # 举例：每只股票的最后一天高亮

fig = hp.plot(
    shares=hp.shares,
    layout='stack',
    highlight={'condition': mask_ml},
)
```

### 关于 Newey–West / Fama–MacBeth 的说明

在计量实证论文中，您可能会看到 **Newey–West（HAC）稳健标准误** 与 **Fama–MacBeth 两步回归**。它们主要用于**回归推断**（标准误修正、风险溢价显著性检验），不属于 `HistoryPanel.zscore()` 这类「基础变换」API 的职责范围。

若需要发表级实证，需要使用 `qteasy` 的 `Strategy` 类创建交易策略，或者将 `HistoryPanel` 导出为 `DataFrame` 后，使用 `statsmodels` 等库完成推断流程（见 **§11**）。


更完整的指标名与参数说明见 [HistoryPanel API 参考](../api/HistoryPanel.rst) 与 `qteasy.tafuncs` 文档。

## 识别蜡烛形态

对于包含完整 OHLC 的面板，还可以用 `HistoryPanel.candle_pattern()` 调用 ta-lib 的蜡烛形态识别函数，快速得到「某形态是否出现」的信号矩阵。这在事件型因子研究（见 [教程 2.8](2.8-historypanel-advanced-event-kline-pattern.md)）中非常常用。

下面的例子识别**锤头线**（`CDLHAMMER`）：

```python
# 识别锤头线，返回 时间 × 股票 的整数信号矩阵（DataFrame）
hammer = hp.candle_pattern(
    name='cdlhammer',
    as_panel=False,

print('锤头线信号（非 0 代表出现形态）:\n', hammer[hammer != 0].dropna(how='all'))
```

- 正数 / 负数：不同方向或强度的形态信号（具体含义取决于 ta-lib 对应函数的定义）。

## 生成研究用 bool 掩码（`where`）

在 §5.2 中我们已经用二维布尔矩阵做 plot 高亮；更一般地，`HistoryPanel.where()` 可以把各种条件统一规整为与面板 **同形状** 的三维 bool 掩码，供 `cum_return`、`normalize`、`portfolio` 等接口的 `mask=` 参数使用。

面板 ``values`` 的轴顺序为 **(标的数 M, 时间长度 L, 指标列数 N)**，与 ``hp.shape`` 一致。``hp.where(condition)`` 返回 **同形** 的 ``numpy.ndarray``（``dtype=bool``），且不修改 ``hp``。``cum_return``、``normalize``、``portfolio`` 已支持 ``mask=hp.where(...)``（或与 ``where`` 同广播规则的 ``bool`` 数组）。

> **注意**：研究向语义与边界（路径断开、基准日无效、组合与 benchmark 关系等）以 API docstring 为准；``where`` 只负责把条件广播成标准掩码。

**与整表数值比较**（与 ``hp.values > 阈值`` 等价）：

```python
import numpy as np

mask = hp.where(hp.values > 0)   # 全表大于 0 的格点为 True
assert mask.shape == hp.shape
print('True 格点数量:', int(mask.sum()))
```

**按时间维打标**（例如某一列索引为「事件日」，沿所有 htype 复制；以下为示意，需保证 ``cond_ml`` 形状为 ``(M, L)``）：

```python
M, L, N = hp.shape
cond_ml = np.zeros((M, L), dtype=bool)
cond_ml[:, -1] = True   # 示例：最后一个交易日标记为 True
mask_event = hp.where(cond_ml)
assert mask_event[:, -1, :].all() and not mask_event[:, 0, :].any()
```

**按收盘价列构造条件**（``callable`` 接收当前 ``HistoryPanel``）：

```python
# 假设存在 'close' 列；多列面板可用 p.values[:, :, idx] 或子面板
mask_close = hp.where(lambda p: p['close'].values[:, :, 0] > 0)
```

**复合条件与缺失值**：

```python
mask_band = hp.where(lambda p: (p.values > -1e9) & (p.values < 1e9))
mask_nan = hp.where(np.isnan(hp.values))   # 标记 NaN 所在格，供排除缺失
```

**说明**：形状恰好为 ``(M, L)`` 的二维条件表示「每个 (标的, 日) 对所有指标列共用同一布尔值」，库内会先扩展为 ``(M, L, 1)`` 再广播到 ``(M, L, N)``。一维 ``(M,)`` 或 ``(M, 1)`` 表示仅随标的变化，会展开为 ``(M, 1, 1)`` 再广播。更完整的参数与异常说明见 [HistoryPanel API 参考](../api/HistoryPanel.rst) 中 ``where`` 一节。

### 累计收益与归一化（`cum_return` / `normalize`）

``cum_return`` 与 ``normalize`` 返回**新的** ``HistoryPanel``（不修改原面板），默认对 ``close`` 列计算；输出列名形如 ``cumret_close``、``norm_close``。可与掩码联用：

```python
m = hp.where(hp.close > 0)           # bool 掩码
cr = hp.cum_return(mask=m, method='simple')   # 累计收益
nm = hp.normalize(base_index=0, mask=m)       # 从 base_index 归一化
```

> **提示**：这是**研究向**收益曲线，不含交易成本；不能替代 ``Operator`` 回测。

### 组合聚合（`portfolio`）

沿**标的维**对指定列做等权或加权平均，返回新 ``HistoryPanel``。``mask=`` 与 ``where`` 使用相同广播规则。指定 ``benchmark`` 时，基准标的不参与组合行聚合，仅用于附加基准曲线或超额列（与 §0 相同）：

```python
ew = hp.portfolio(mode='equal', benchmark_output='none')   # 等权组合
m = hp.where(hp.close > 0)
ew_m = hp.portfolio(mode='equal', mask=m, benchmark_output='none')
# 含基准时：tagged = hp.portfolio(..., benchmark='000300.SH', benchmark_output='tag_along', new_share_name='EW')
```

### 列属性、比较与 ``loc``（与 pandas 的差异）

- **列属性（只读）**：列名为合法 Python 标识符时可用 ``hp.close``，等价 ``hp['close']``；含 ``|`` 的复权列名等须用方括号。赋值请统一 ``hp['col'] = ...``。
- **比较**：``hp.close > hp.open``、``hp > 0`` 等得到 **``numpy.ndarray``（bool）**，不是子 ``HistoryPanel``；全形掩码可写 ``hp.where(hp.close > 15)``。两侧均为面板时须 ``shares``、``hdates`` 一致；两列比较时多为两个 **单列** 子面板。
- **``loc``**：``hp.loc[s]`` 等价 ``hp[:, :, s]``，只沿 **时间（hdates）** 轴筛选；**不要**把 ``where`` 得到的 ``(M, L, N)`` 掩码传给 ``loc``，格点条件仍用 ``where`` + 后续 ``mask=``。

细节与边界情况以 [HistoryPanel API 参考](../api/HistoryPanel.rst) 为准（含 ``where``、``cum_return``、``normalize``、``portfolio``）。

```python
# 示意（在已含 open/close 列的 hp 上）
# m = hp.where(hp.close > hp.open)   # 比较 → bool ndarray → where 广播到 (M,L,N)
# tail = hp.loc[-5:]                 # 仅时间轴，等价 hp[:, :, -5:]
```

## 从 HistoryPanel 研究到 Strategy / Operator：迁移路径

读到这里，您已经能在 `HistoryPanel` 上完成取数、算因子、做粗组合与出图。若研究结论需要**严肃评价**或**实盘准备**，下一步应把同一套经济含义写进策略的 `realize()`，交给 `Operator` + `Backtester`——它们才包含交割、手续费、滑点、信号类型（PT/PS/VS）等完整账户语义。

> **注**：`HistoryPanel` 上的 `cum_return`、`portfolio` 等仍是**研究向**工具，便于肉眼筛因子；**不能**替代正式回测报告。

下面用**同一思想——20 期简单动量**串起两阶段（需本地已配置数据源；股票代码仅为示意）。完整脚本见 ``examples/historypanel_research_to_strategy.py``。

### 研究阶段：在多标的 `HistoryPanel` 上算因子并粗看截面

```python
import numpy as np
import qteasy as qt

# 9.1 拉取多标的日线收盘价（htype 以本地数据源为准，可为 close 或复权列 close|b）
hp = qt.get_history_data(
    htypes='close',
    shares=['000001.SZ', '000002.SZ', '600000.SH'],
    start='20200101',
    end='20231231',
    freq='d',
    as_data_frame=False,
)

# 20 期简单动量：r_t = P_t / P_{t-20} - 1
hp_mom = hp.returns(price_htype='close', periods=20, method='simple', as_panel=True)

# 截面排名：逐日比较多标的强弱（研究向）
hp_rank = hp_mom.rank(by='ret_close')

# 等权组合在收益列上的逐日平均，仅用于目视
hp_ew = hp_mom.portfolio(htypes='ret_close', mode='equal', benchmark_output='none')

hp_mom.plot(shares=hp_mom.shares, layout='stack')
```

若动量曲线与排名结果符合预期，即可进入 9.2，把因子定义**固化**到策略类中。

### 正式回测阶段：`FactorSorter` + `Operator`

选股类策略常用 `FactorSorter`：`realize()` 返回**每个标的一个标量因子**（长度 = 股票数），框架再按 `max_sel_count`、`sort_ascending` 等排序与赋权。下面动量与 9.1 中 `returns(..., periods=20)` 的经济含义一致，但数据来自策略窗口注入（与回测步对齐，受 `use_latest_data_cycle` 等约束，**防前视**）。

```python
import numpy as np
import qteasy as qt
from qteasy import StgData


class Mom20Factor(qt.FactorSorter):
    """20 期收盘动量：close[-1]/close[0]-1，与 HP 上 returns(periods=20) 语义对齐。"""

    def __init__(self) -> None:
        super().__init__(
            name='Mom20',
            description='20-bar simple momentum on daily close',
            data_types=[StgData('close', freq='d', asset_type='E')],
            window_length=21,
            max_sel_count=3,
            sort_ascending=False,
            condition='any',
            use_latest_data_cycle=True,
        )

    def realize(self):
        close_w = self.get_data('close_E_d')   # 形状约为 (window_length, 股票数)
        out = close_w[-1] / close_w[0] - 1.0
        out = np.where(np.isfinite(out), out, np.nan)
        return out


# 以下为骨架：具体 run 参数（股票池、起止日、费率、signal_type 等）见「回测」与 Operator 文档
op = qt.Operator()
op.add_strategy(Mom20Factor(), run_freq='d', run_timing='close')
# res = qt.run(op, mode=1, ...)  # 按项目文档填写 shares、起止日期与回测配置
```

**注意**：

- `Operator` 默认组内可使用 PT 类目标仓位信号；`FactorSorter` 与 PT 的搭配以 [教程 3](3-start-first-strategy.md) 及回测文档为准。
- HP 上用全样本算的 rank/zscore，与回测中「每步仅见历史窗口」的因子可能略有数值差异，属预期现象；应以策略内 `get_data` 为准。

## 多源数据拼成 `HistoryPanel`（价格 + 基本面示例）

研究里常见需求是把**不同表、不同字段**放进同一块面板里一起算因子——例如收盘价 + 市净率（PB）做估值因子。`HistoryPanel` 可以承载任意 `htypes` 列；实践中通常有两种做法：

1. **一次** `get_history_data` 拉多列（频率与资产类型须一致，最简单）；
2. 分别取两块面板，再 `align_to` 对齐后合并。

可运行演示见 ``examples/historypanel_multisource_research.py``。

### 单次拉取多列（推荐优先尝试）

若本地已有日线 `close` 与 `pb`（市净率）等字段，可直接一次拉取：

```python
import numpy as np
import qteasy as qt

# 10.1 一次拉取 close 与 pb 两列
hp = qt.get_history_data(
    htypes='close, pb',
    shares=['000001.SZ', '000002.SZ'],
    start='20200101',
    end='20231231',
    freq='d',
)

# 派生账面市值比近似（bp = 1/pb，仅作演示，非投资建议）
hp2 = hp.assign(bp=lambda p: 1.0 / np.maximum(p['pb'].values[:, :, 0], 1e-8))

# 横截面 zscore：逐日可比
hp_z = hp2.zscore(by='bp', method='cs')
```

> **注意**：缺列或表未下载时，`get_history_data` 会报错；请先通过 [教程 2.0](2.0-get-data.md) 补齐表数据。

### 两块面板对齐后再派生（不同来源 / 分次拉取）

当价格与基本面来自**不同拉取步骤**时，先用 ``align_to`` 对齐 ``shares`` 与 ``hdates``，再运算。``align_to`` 要求两侧 **``htypes`` 名称与顺序完全一致**——若您分别只拉了 ``close`` 与 ``pb``，需先扩成同构列（缺失侧用 ``NaN`` 占位）：

```python
import numpy as np
import qteasy as qt

pool = ['000001.SZ', '000002.SZ']
hp_px = qt.get_history_data(htypes='close', shares=pool, start='20200101', end='20231231', freq='d')
hp_pb = qt.get_history_data(htypes='pb', shares=pool, start='20200101', end='20231231', freq='d')

c = hp_px['close'].values[:, :, 0]
p = hp_pb['pb'].values[:, :, 0]
nan_c = np.full_like(c, np.nan)
nan_p = np.full_like(p, np.nan)

# 手工同构：两侧 htypes 均为 ['close', 'pb']，缺失列填 NaN
hp_a = qt.HistoryPanel(
    np.stack([c, nan_p], axis=2),
    levels=hp_px.shares,
    rows=hp_px.hdates,
    columns=['close', 'pb'],
)
hp_b = qt.HistoryPanel(
    np.stack([nan_c, p], axis=2),
    levels=hp_pb.shares,
    rows=hp_pb.hdates,
    columns=['close', 'pb'],
)

a, b = hp_a.align_to(hp_b, join='inner')   # 交集对齐，避免 silent 错行
hp_joined = a.assign(
    close=lambda x: a['close'].values[:, :, 0],
    pb=lambda x: b['pb'].values[:, :, 0],
)
```

> **提示**：若数据源允许，优先用 **§10.1** 一次 ``get_history_data(htypes='close, pb', ...)``，少一步手工同构。核心原则仍是 **先对齐再运算**。

## 导出到 pandas / statsmodels（宽表、长表与截面回归）

§5.3 提到 Newey–West、Fama–MacBeth 等**回归推断**不在 `HistoryPanel` 核心 API 内。若您需要发表级实证，应把面板**导出为二维表**，再用 `statsmodels` 等库完成推断。

合成数据示例见 ``examples/historypanel_statsmodels_export.py``。

### 按标的切成多个 `DataFrame`（宽表）

``to_df_dict(by='share')`` 会把每只标的拆成一张标准 ``DataFrame``（index 为时间，columns 为 htypes），便于在 pandas 里做常规分析：

```python
by_share = hp.to_df_dict(by='share')
df_000001 = by_share['000001.SZ']   # index 为时间，columns 为 htypes
```

### 手工堆成长表（便于按日截面分组）

若要做「固定某日、对所有股票回归」这类截面分析，常需把三维面板**堆成长表**（每行 = 某日某股）：

```python
import pandas as pd

records = []
M, L, N = hp.shape
ci = hp.htypes.index('close')
fi = hp.htypes.index('factor')   # 假设已通过 assign 等追加名为 factor 的列
for mi, sh in enumerate(hp.shares):
    for li, dt in enumerate(hp.hdates):
        records.append({
            'date': dt,
            'share': sh,
            'close': hp.values[mi, li, ci],
            'factor': hp.values[mi, li, fi],
        })
df_long = pd.DataFrame(records)
```

### 单日截面 OLS 示例（需已安装 statsmodels）

下面演示**固定一个交易日**、对截面做 OLS；因变量仅为示意，实务中应使用**前瞻收益**并与因子正确对齐：

```python
# pip install statsmodels
import statsmodels.api as sm

sub = df_long[df_long['date'] == df_long['date'].iloc[-100]].dropna()
y = sub['close'] / sub['close'].mean() - 1.0   # 示例因变量；实务常用前瞻收益
X = sm.add_constant(sub['factor'])
model = sm.OLS(y, X, missing='drop').fit()
print(model.summary())
```

> **注意**：停牌、幸存者偏差、因子与收益对齐等问题，应在**计量层**（pandas / statsmodels）处理，而非 `HistoryPanel` 的职责。
